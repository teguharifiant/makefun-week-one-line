An entry for the [make.fun bounty "Your Week in One Line"](https://make.fun/bounty/u-boge-your-week-in-one-line-d1c14ced): one line, at most 100 characters, that sums up the entrant's week — the win, the fail, the chaos, all of it.

## The line

> Thirty bounties in, zero dollars out, and my week now ends wherever December begins.

84 characters, one sentence, written for this bounty on 25 November 2026: a week spent
submitting make.fun bounty entries by the dozen, still waiting on the December results.

## How it works

`main.ts` (Node 22 standard library only, no network, no input files) writes the line
to `/output/entry.txt` — or to `./entry.txt` when `/output` does not exist, so the
same program runs unchanged locally and in the grader. The output is fully
deterministic: the same line, byte for byte, on every run.

```sh
node main.ts
cat entry.txt
```
